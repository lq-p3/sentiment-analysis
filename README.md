# 🏗️ دليل مشروع تورلايز (Touralyze) — محلل المشاعر السياحية الذكي

## 📌 نظرة عامة
نظام ذكي يحلل مشاعر السياح تجاه المدن السعودية عبر سحب التقييمات من Google Maps وتحليلها بنموذج ذكاء اصطناعي عربي (CAMeLBERT).

---

## 🔄 تسلسل عمل النظام (من البداية للنهاية)

```
المستخدم يكتب "العلا" ← React يرسل الطلب ← C# ينشئ تقرير ← C# يرسل لـ Python
← Python يسحب التقييمات من Google Maps ← Python يحلل المشاعر بـ CAMeLBERT
← Python يرجع النتائج ← C# يحفظها بقاعدة البيانات ← React يعرض الرسوم البيانية
```

## ❓ أسئلة المناقشة المتوقعة

### س1: لماذا قسمتم المشروع إلى واجهتين خلفيتين (C# و Python)؟
> استخدمنا معمارية الخدمات المصغرة (Microservices). C# للـ API الأساسي وإدارة البيانات والأمان لأنه قوي وسريع. Python لأنه اللغة الأقوى لتشغيل نماذج الذكاء الاصطناعي (HuggingFace/CAMeLBERT). هذا الفصل يجعل النظام قابلاً للتوسع.

### س2: كيف يتم سحب البيانات من خرائط جوجل؟
> نستخدم Selenium لفتح متصفح Chrome بدون واجهة (Headless)، يبحث عن المكان في Google Maps، يضغط على المراجعات، وينزل للأسفل تلقائياً لجمع التقييمات. نتجنب الحظر بإخفاء أنه روبوت.

### س3: ما هو نموذج الـ AI المستخدم ولماذا؟
> نموذج CAMeLBERT-da-sentiment من مختبر CAMeL بجامعة نيويورك أبوظبي. اخترناه لأنه مخصص للهجات العربية وليس فقط الفصحى، والسياح يكتبون بالعامية غالباً.

### س4: كيف حميتم كلمات المرور؟
> لا نخزن كلمات المرور أبداً. نستخدم BCrypt لعمل Hashing + Salting. ونستخدم JWT Token للجلسات بدون حفظ بيانات في السيرفر.

### س5: لماذا TypeScript بدلاً من JavaScript؟
> TypeScript يكشف الأخطاء وقت كتابة الكود (قبل التشغيل) لأنه يشترط تعريف أنواع البيانات. هذا يقلل الأخطاء ويسرّع التطوير.

### س6: ما هي الـ DTOs ولماذا تستخدمونها؟
> Data Transfer Objects — كائنات نقل البيانات. نستخدمها لتحديد ما نرسله للمتصفح بدون كشف كل أعمدة قاعدة البيانات (مثلاً نرسل بيانات المستخدم بدون الباسورد).

### س7: كيف تمنعون تكرار التقارير والتقييمات؟
> نستخدم SHA256 Hash. لكل تقرير نحسب مفتاح فريد من (المستخدم + المدينة + المصادر + التاريخ). لو نفس الطلب تكرر نرجع التقرير القديم بدل إعادة التحليل.

### س8: ماذا يحدث لو فشل سيرفر Python؟
> الـ C# يغلف الطلب بـ try-catch. لو فشل، يغير حالة التقرير لـ "Failed" ويرجع خطأ 500 للمستخدم بدون ما ينهار النظام.

### س9: ما الفرق بين مجلد src ومجلد dist؟
> src = ملفات التطوير (الكود الأصلي الذي نكتبه). dist = النسخة النهائية المبنية والمضغوطة الجاهزة للنشر على الإنترنت.

### س10: كيف يدعم الموقع اللغتين العربية والإنجليزية؟
> نستخدم React Context API. ملف LanguageContext يحفظ اللغة الحالية ويغير اتجاه الصفحة (RTL/LTR). وكل النصوص في ملفات ترجمة منفصلة (ar.ts و en.ts) ونستدعيها بدالة t('key').

## 🚀 تشغيل المشروع

```bash

venv/bin/python main.py          # يعمل على http://localhost:8000

# 2. تشغيل الواجهة الخلفية (C#)
cd SmartTourism.API
dotnet run                       # يعمل على http://localhost:5165

# 3. تشغيل الواجهة الأمامية (React)
npm run dev                      # يعمل على http://localhost:3000
```
