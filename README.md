# Touralyze

AI-powered tourism sentiment analysis platform for Arabic reviews and tourism analytics.

---

## Overview

Touralyze is an intelligent tourism analytics platform that analyzes Arabic reviews from tourism-related sources using Artificial Intelligence and Natural Language Processing (NLP).

The system helps tourism organizations understand visitor satisfaction, detect trends, and generate analytics reports through an interactive dashboard.

---

## Features

- Arabic sentiment analysis using AI
- Interactive analytics dashboard
- Google Maps reviews analysis
- Bilingual interface (Arabic / English)
- PDF report generation
- Authentication and OTP verification
- AI-powered insights
